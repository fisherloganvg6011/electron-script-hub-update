## Frequently Asked Questions

**Is Electron safe to use?**  
Electron is supplied as-is for educational and testing use. Each user is responsible for following Roblox's Terms of Service. The software does not contain malicious code, but it is used at the user's own risk.

**Does Electron support the newest Roblox release?**  
Its automatic update engine is intended to maintain support for recent Roblox builds. If a problem occurs, look in the repository for a newer release.

**What does Electron offer compared with other free executors?**  
Electron operates without a key and combines a 500+ script hub with persistent queuing and batch execution. These capabilities are not included in every free tool.

**Could using Electron lead to an account ban?**  
Third-party execution tools breach Roblox's Terms of Service and can lead to suspension or termination. Use the software responsibly and consider alternate accounts.

**Where does Electron save scripts?**  
Scripts added by the user remain on the computer inside `scripts/`. The hub index is stored in `hub/`, where it may also be refreshed manually.
